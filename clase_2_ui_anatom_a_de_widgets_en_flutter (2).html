3. El Modelo Mental del Árbol de Widgets (Widget Tree)

Entiende cómo Flutter piensa y organiza los elementos visuales en una estructura de árbol jerárquica.

La Regla de Oro del Renderizado en Flutter

1. Constraints go down

El widget padre le indica a sus hijos las restricciones de espacio disponible (ancho y alto mínimo y máximo).

2. Sizes go up

El widget hijo decide cuál es su propio tamaño respetando las restricciones y se lo notifica a su padre.

3. Parent sets position

El widget padre toma el tamaño decidido por el hijo y lo ubica en las coordenadas exactas dentro del lienzo visual.

1. Leaf Widgets (Sin Hijos)

Son el final de la rama. Renderizan contenido gráfico puro y no pueden contener otros widgets dentro.

Text('Hola')
Icon(Icons.add)
Image.asset('logo.png')

2. Single-Child Widgets (Un Hijo)

Aceptan exactamente **un solo widget hijo** mediante la propiedad child:. Se usan para dar formato, margen o alineación.

Container(child: ...)
Padding(child: ...)
Center(child: ...)

3. Multi-Child Widgets (Muchos)

Aceptan una lista ordenada de **múltiples widgets hijos** mediante la propiedad children: [...].

Column(children: [...])
Row(children: [...])
ListView(children: [...])

Lógica Dart: Validaciones y Refresco mediante `setState()`

                        
Escribimos las funciones que procesarán los textos ingresados por el usuario.

                    

                


                

                    

                        

                            💡 Explicación de las Funciones Dart:
                            
    
                                
  • `_num1Controller.text.trim()`: Obtiene la cadena de texto ingresada eliminando espacios en blanco accidentales.
    • 
                                
  • `double.tryParse(t1)`: Intenta convertir el texto a un número decimal (`double`). Si el texto contiene letras o coma inválida, retorna `null`.
    • 
                                
  • `setState(() { ... })`: La función más importante de Flutter. Notifica al Framework que el estado cambió para que vuelva a ejecutar el método build() y redibuje la pantalla con el nuevo resultado.
    • 
                            

                        


                        

                            

                                Paso 2: Métodos _realizarSuma() y _limpiar()
                                
                            


  void _realizarSuma() {
    final t1 = _num1Controller.text.trim();
    final t2 = _num2Controller.text.trim();

    if (t1.isEmpty || t2.isEmpty) {
      setState(() {
        _resultado = "Por favor ingresa ambos números";
        _huboError = true;
      });
      return;
    }

    final double? n1 = double.tryParse(t1);
    final double? n2 = double.tryParse(t2);

    if (n1 == null || n2 == null) {
      setState(() {
        _resultado = "Número inválido ingresado";
        _huboError = true;
      });
      return;
    }

    setState(() {
      _resultado = "${n1 + n2}";
      _huboError = false;
    });
  }

  void _limpiar() {
    _num1Controller.clear();
    _num2Controller.clear();
    setState(() {
      _resultado = "0.0";
      _huboError = false;
    });
  }

                        

                    


                    

                        📱 Flujo de Control en Memoria:

                                2. `double.tryParse("12.5")` ➔ `12.5`
                            

                            

                                3. `setState()` dispara redibujado de la pantalla

import 'package:flutter/material.dart';

/// RETO 1 · Cotizador Express de Envíos Nacionales
/// Archivo: lib/screens/cotizador_screen.dart
class CotizadorScreen extends StatefulWidget {
  const CotizadorScreen({super.key});

  @override
  State<CotizadorScreen> createState() => _CotizadorScreenState();
}

class _CotizadorScreenState extends State<CotizadorScreen> {
  final TextEditingController _pesoController =
      TextEditingController(text: '2.5');

  // Costo base del flete según la ciudad de destino
  final Map<String, double> _ciudades = {
    'Bogotá': 8000,
    'Medellín': 12000,
    'Cali': 14000,
  };

  // Recargo según la velocidad del servicio
  final Map<String, double> _velocidades = {
    'Estándar': 0,
    'Express': 5000,
    'Súper Express': 10000,
  };

  String _ciudadSeleccionada = 'Bogotá';
  String _tipoEnvio = 'Estándar';
  bool _conSeguro = false;

  double _total = 0;
  bool _calculado = false;

  @override
  void dispose() {
    _pesoController.dispose();
    super.dispose();
  }

  void _calcularEnvio() {
    final double peso =
        double.tryParse(_pesoController.text.replaceAll(',', '.')) ?? 0;

    final double costoCiudad = _ciudades[_ciudadSeleccionada]!;
    final double costoVelocidad = _velocidades[_tipoEnvio]!;
    final double costoSeguro = _conSeguro ? 3000 : 0;

    setState(() {
      _total = costoCiudad + (peso * 2000) + costoVelocidad + costoSeguro;
      _calculado = true;
    });
  }

  // Convierte 13000 en el texto $13.000
  String _pesos(double valor) {
    final String entero = valor.round().toString();
    final RegExp patron = RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))');
    return '\$${entero.replaceAllMapped(patron, (Match m) => '${m[1]}.')}';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Cotizador de Envíos'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // 1. PESO DEL PAQUETE
            TextField(
              controller: _pesoController,
              keyboardType:
                  const TextInputType.numberWithOptions(decimal: true),
              decoration: InputDecoration(
                labelText: 'Peso del paquete (Kg)',
                hintText: 'Ej. 2.5',
                prefixIcon: const Icon(Icons.scale),
                filled: true,
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 16),

            // 2. CIUDAD DE DESTINO
            DropdownButtonFormField<String>(
              value: _ciudadSeleccionada,
              decoration: InputDecoration(
                labelText: 'Ciudad de destino',
                prefixIcon: const Icon(Icons.location_city),
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
              items: _ciudades.keys.map((String ciudad) {
                return DropdownMenuItem<String>(
                  value: ciudad,
                  child: Text('$ciudad  ·  ${_pesos(_ciudades[ciudad]!)}'),
                );
              }).toList(),
              onChanged: (String? valor) {
                if (valor == null) return;
                setState(() => _ciudadSeleccionada = valor);
              },
            ),
            const SizedBox(height: 16),

            // 3. TIPO DE ENVÍO (RadioListTile)
            Card(
              elevation: 1,
              child: Column(
                children: _velocidades.keys.map((String tipo) {
                  return RadioListTile<String>(
                    dense: true,
                    title: Text(tipo),
                    subtitle: Text('Recargo: ${_pesos(_velocidades[tipo]!)}'),
                    value: tipo,
                    groupValue: _tipoEnvio,
                    onChanged: (String? valor) {
                      if (valor == null) return;
                      setState(() => _tipoEnvio = valor);
                    },
                  );
                }).toList(),
              ),
            ),
            const SizedBox(height: 8),

            // 4. SEGURO OPCIONAL (SwitchListTile)
            Card(
              elevation: 1,
              child: SwitchListTile(
                title: const Text('Seguro de mercancía'),
                subtitle: const Text('Cobertura adicional por \$3.000'),
                secondary: const Icon(Icons.verified_user),
                value: _conSeguro,
                onChanged: (bool valor) {
                  setState(() => _conSeguro = valor);
                },
              ),
            ),
            const SizedBox(height: 20),

            // 5. BOTÓN QUE EJECUTA EL CÁLCULO
            ElevatedButton.icon(
              onPressed: _calcularEnvio,
              icon: const Icon(Icons.calculate),
              label: const Text('COTIZAR ENVÍO'),
              style: ElevatedButton.styleFrom(
                backgroundColor: Colors.indigo,
                foregroundColor: Colors.white,
                padding: const EdgeInsets.symmetric(vertical: 14),
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 20),

            // 6. TARJETA DE RESULTADO
            Card(
              elevation: 0,
              color: Colors.indigo.shade50,
              shape: RoundedRectangleBorder(
                side: BorderSide(color: Colors.indigo.shade100),
                borderRadius: BorderRadius.circular(16),
              ),
              child: Padding(
                padding: const EdgeInsets.all(16.0),
                child: Column(
                  children: [
                    Text(
                      _calculado
                          ? 'VALOR TOTAL COTIZADO'
                          : 'PRESIONA COTIZAR PARA VER EL VALOR',
                      style: TextStyle(
                        fontSize: 11,
                        fontWeight: FontWeight.bold,
                        color: Colors.indigo.shade700,
                      ),
                    ),
                    const SizedBox(height: 6),
                    Text(
                      _calculado ? _pesos(_total) : '--',
                      style: const TextStyle(
                        fontSize: 26,
                        fontWeight: FontWeight.w900,
                        color: Color(0xFF1A237E),
                      ),
                    ),
                    if (_calculado) ...[
                      const SizedBox(height: 6),
                      Text(
                        '$_ciudadSeleccionada · $_tipoEnvio'
                        '${_conSeguro ? ' · Con seguro' : ''}',
                        style: const TextStyle(fontSize: 11),
                      ),
                    ],
                  ],
                ),
              ),
            ),
          ],
        ),
      ),
    );
  }
}

  final TextEditingController _cuentaController =
      TextEditingController(text: '120000');

  int _propina = 10;   // Porcentaje elegido en el SegmentedButton
  int _personas = 3;   // Cantidad ajustada con los IconButton

  @override
  void dispose() {
    _cuentaController.dispose();
    super.dispose();
  }

  double get _cuenta =>
      double.tryParse(_cuentaController.text.replaceAll(',', '.')) ?? 0;

  double get _totalConPropina => _cuenta * (1 + _propina / 100);

  double get _montoPorPersona => _totalConPropina / _personas;

  void _cambiarPersonas(int delta) {
    setState(() {
      _personas = (_personas + delta).clamp(1, 20);
    });
  }

  String _pesos(double valor) {
    final String entero = valor.round().toString();
    final RegExp patron = RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))');
    return '\$${entero.replaceAllMapped(patron, (Match m) => '${m[1]}.')}';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Propinas y División'),
        backgroundColor: Colors.deepPurple,
        foregroundColor: Colors.white,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // 1. TOTAL DE LA CUENTA
            TextField(
              controller: _cuentaController,
              keyboardType:
                  const TextInputType.numberWithOptions(decimal: true),
              onChanged: (_) => setState(() {}), // Recalcula en vivo
              decoration: InputDecoration(
                labelText: 'Total de la cuenta',
                prefixIcon: const Icon(Icons.attach_money),
                filled: true,
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 20),

            // 2. PROPINA SUGERIDA (SegmentedButton)
            const Text(
              'Propina sugerida',
              style: TextStyle(fontWeight: FontWeight.bold, fontSize: 13),
            ),
            const SizedBox(height: 8),
            SegmentedButton<int>(
              segments: const <ButtonSegment<int>>[
                ButtonSegment<int>(value: 10, label: Text('10%')),
                ButtonSegment<int>(value: 15, label: Text('15%')),
                ButtonSegment<int>(value: 20, label: Text('20%')),
              ],
              selected: <int>{_propina},
              onSelectionChanged: (Set<int> seleccion) {
                setState(() => _propina = seleccion.first);
              },
            ),
            const SizedBox(height: 20),

            // 3. NÚMERO DE PERSONAS (IconButton + / -)
            Card(
              elevation: 1,
              child: Padding(
                padding: const EdgeInsets.symmetric(
                    horizontal: 12.0, vertical: 6.0),
                child: Row(
                  mainAxisAlignment: MainAxisAlignment.spaceBetween,
                  children: [
                    const Text(
                      'Personas',
                      style: TextStyle(fontWeight: FontWeight.bold),
                    ),
                    Row(
                      children: [
                        IconButton(
                          icon: const Icon(Icons.remove_circle_outline),
                          onPressed: () => _cambiarPersonas(-1),
                        ),
                        Text(
                          '$_personas',
                          style: const TextStyle(
                            fontSize: 18,
                            fontWeight: FontWeight.bold,
                          ),
                        ),
                        IconButton(
                          color: Colors.deepPurple,
                          icon: const Icon(Icons.add_circle),
                          onPressed: () => _cambiarPersonas(1),
                        ),
                      ],
                    ),
                  ],
                ),
              ),
            ),
            const SizedBox(height: 20),

            // 4. RESULTADO
            Card(
              elevation: 0,
              color: Colors.deepPurple.shade50,
              shape: RoundedRectangleBorder(
                side: BorderSide(color: Colors.deepPurple.shade100),
                borderRadius: BorderRadius.circular(16),
              ),
              child: Padding(
                padding: const EdgeInsets.all(16.0),
                child: Column(
                  children: [
                    Text(
                      'PAGA CADA PERSONA',
                      style: TextStyle(
                        fontSize: 11,
                        fontWeight: FontWeight.bold,
                        color: Colors.deepPurple.shade700,
                      ),
                    ),
                    const SizedBox(height: 6),
                    Text(
                      _pesos(_montoPorPersona),
                      style: const TextStyle(
                        fontSize: 26,
                        fontWeight: FontWeight.w900,
                      ),
                    ),
                    const Divider(height: 20),
                    Text('Cuenta: ${_pesos(_cuenta)}'),
                    Text('Propina ($_propina%): '
                        '${_pesos(_totalConPropina - _cuenta)}'),
                    Text('Total con propina: ${_pesos(_totalConPropina)}'),
                  ],
                ),
              ),
            ),
          ],
        ),
      ),
    );
  }
}

import 'package:flutter/material.dart';

/// RETO 4 · Agendamiento de Citas Médicas
/// Archivo: lib/screens/citas_screen.dart
class CitasScreen extends StatefulWidget {
  const CitasScreen({super.key});

  @override
  State<CitasScreen> createState() => _CitasScreenState();
}

class _CitasScreenState extends State<CitasScreen> {
  final List<String> _especialidades = [
    'Medicina General',
    'Odontología',
    'Pediatría',
  ];

  final List<String> _horas = ['08:00 AM', '10:30 AM', '02:00 PM'];

  String _especialidad = 'Medicina General';
  String _hora = '08:00 AM';
  DateTime? _fechaSeleccionada;
  bool _reservaConfirmada = false;

  /// Abre el calendario nativo de Material y espera la respuesta
  Future<void> _elegirFecha() async {
    final DateTime ahora = DateTime.now();

    final DateTime? fecha = await showDatePicker(
      context: context,
      initialDate: _fechaSeleccionada ?? ahora,
      firstDate: ahora,
      lastDate: DateTime(ahora.year + 1),
      helpText: 'Selecciona la fecha de tu cita',
    );

    if (fecha != null) {
      setState(() {
        _fechaSeleccionada = fecha;
        _reservaConfirmada = false;
      });
    }
  }

  // Convierte un DateTime en el texto dd/mm/aaaa
  String _formatoFecha(DateTime fecha) {
    final String dia = fecha.day.toString().padLeft(2, '0');
    final String mes = fecha.month.toString().padLeft(2, '0');
    return '$dia/$mes/${fecha.year}';
  }

  void _confirmarReserva() {
    if (_fechaSeleccionada == null) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Primero selecciona una fecha para la cita'),
          backgroundColor: Colors.redAccent,
        ),
      );
      return;
    }

    setState(() => _reservaConfirmada = true);

    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('Cita reservada: $_especialidad · $_hora'),
        backgroundColor: Colors.teal,
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Agendar Cita Médica'),
        backgroundColor: Colors.teal,
        foregroundColor: Colors.white,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // 1. ESPECIALIDAD
            DropdownButtonFormField<String>(
              value: _especialidad,
              decoration: InputDecoration(
                labelText: 'Especialidad',
                prefixIcon: const Icon(Icons.medical_services),
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
              items: _especialidades.map((String esp) {
                return DropdownMenuItem<String>(value: esp, child: Text(esp));
              }).toList(),
              onChanged: (String? valor) {
                if (valor == null) return;
                setState(() {
                  _especialidad = valor;
                  _reservaConfirmada = false;
                });
              },
            ),
            const SizedBox(height: 16),

            // 2. FECHA CON showDatePicker()
            OutlinedButton.icon(
              onPressed: _elegirFecha,
              icon: const Icon(Icons.calendar_month),
              label: Text(
                _fechaSeleccionada == null
                    ? 'Seleccionar fecha de la cita'
                    : 'Fecha: ${_formatoFecha(_fechaSeleccionada!)}',
              ),
              style: OutlinedButton.styleFrom(
                padding: const EdgeInsets.symmetric(vertical: 14),
                side: const BorderSide(color: Colors.teal),
                foregroundColor: Colors.teal,
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 20),

            // 3. HORA DISPONIBLE (ChoiceChip)
            const Text(
              'Hora disponible',
              style: TextStyle(fontWeight: FontWeight.bold, fontSize: 13),
            ),
            const SizedBox(height: 8),
            Wrap(
              spacing: 8.0,
              children: _horas.map((String hora) {
                return ChoiceChip(
                  label: Text(hora),
                  selected: _hora == hora,
                  selectedColor: Colors.teal.shade100,
                  onSelected: (bool seleccionado) {
                    if (!seleccionado) return;
                    setState(() {
                      _hora = hora;
                      _reservaConfirmada = false;
                    });
                  },
                );
              }).toList(),
            ),
            const SizedBox(height: 20),

            ElevatedButton.icon(
              onPressed: _confirmarReserva,
              icon: const Icon(Icons.event_available),
              label: const Text('CONFIRMAR RESERVA'),
              style: ElevatedButton.styleFrom(
                backgroundColor: Colors.teal,
                foregroundColor: Colors.white,
                padding: const EdgeInsets.symmetric(vertical: 14),
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 20),

            // 4. TICKET VIRTUAL DE CONFIRMACIÓN
            if (_reservaConfirmada)
              Card(
                elevation: 0,
                color: Colors.teal.shade50,
                shape: RoundedRectangleBorder(
                  side: BorderSide(color: Colors.teal.shade200),
                  borderRadius: BorderRadius.circular(16),
                ),
                child: Padding(
                  padding: const EdgeInsets.all(16.0),
                  child: Column(
                    crossAxisAlignment: CrossAxisAlignment.start,
                    children: [
                      Row(
                        children: [
                          const Icon(Icons.confirmation_number,
                              color: Colors.teal),
                          const SizedBox(width: 8),
                          Text(
                            'TICKET VIRTUAL',
                            style: TextStyle(
                              fontWeight: FontWeight.bold,
                              color: Colors.teal.shade800,
                            ),
                          ),
                        ],
                      ),
                      const Divider(height: 20),
                      Text('Especialidad: $_especialidad'),
                      Text('Fecha: ${_formatoFecha(_fechaSeleccionada!)}'),
                      Text('Hora: $_hora'),
                      const SizedBox(height: 6),
                      const Text(
                        'Presenta este ticket 15 minutos antes.',
                        style: TextStyle(fontSize: 11, color: Colors.black54),
                      ),
                    ],
                  ),
                ),
              ),
          ],
        ),
      ),
    );
  }
}
