Fundamento Técnico

3. ¿Cómo Funciona Realmente la Navegación en Flutter?

Comprende los widgets internos que gestionan la pila de pantallas y el rol de `BuildContext` y `MaterialPageRoute`.

1. El Widget `Navigator`

En Flutter, `Navigator` es un **StatefulWidget** que administra un widget especial llamado Overlay. El `Overlay` gestiona una lista flotante de elementos gráficos ordenados visualmente uno sobre otro.

NavigatorState state = Navigator.of(context);

2. `MaterialPageRoute`

Es una ruta modal que reemplaza toda la pantalla con una animación de transición nativa. En **Android** se desliza verticalmente con desvanecimiento; en **iOS** entra desde la derecha.

MaterialPageRoute(builder: (context) => NuevaPantalla())

3. El Rol de `BuildContext`

El `context` es el **mapa de posición** de un widget en el árbol. Cuando llamas a `Navigator.push(context, ...)`, Flutter busca hacia arriba en el árbol el widget `Navigator` más cercano.

// Busca el Navigator en el ancestro

Rutas Anónimas (`push`) vs Rutas Nombradas (`pushNamed`)

Estrategia Código de Uso Ventaja Principal Uso Recomendado
Rutas Anónimas Navigator.push(context, MaterialPageRoute(...)) Permite pasar objetos directamente en el constructor. Apps pequeñas, listas dinámicas con parámetros.
Rutas Nombradas Navigator.pushNamed(context, '/cotizador') Centraliza las rutas en un mapa global dentro de `MaterialApp`. Apps medianas/grandes con menús fijos.
Fundamentos de POO & Arquitectura

4. ¿Por qué usamos Modelos de Datos en POO y Estructura `lib/`?

Supera la práctica de escribir todo en un solo archivo `main.dart`. Descubre el valor pedagógico de la Programación Orientada a Objetos en Flutter.

🧠 ¿Qué es una Clase Modelo y Por Qué la Necesitamos?

En la semana pasada creaste aplicaciones en archivos independientes. Ahora, para unirlas en un solo menú con ListView.builder, necesitamos representar las opciones del menú como **objetos del mundo real**. En Dart, esto se logra mediante **Programación Orientada a Objetos (POO)**.

1. Tipado Fuerte (Strong Typing)

En lugar de usar Listas de Mapas genéricos (Map<String, dynamic>) propensos a errores de tipeo, una clase como Herramienta le exige al compilador que cada ítem tenga exactamente las propiedades esperadas.

2. Polimorfismo & Widgets como Objetos

En Flutter, las pantallas secundarias (CotizadorScreen, EncuestaScreen) son clases que heredan de Widget. ¡Por eso podemos guardar una pantalla completa dentro del atributo final Widget pantallaDestino!

3. Desacoplamiento Limpio

Separar la estructura del objeto (models/herramienta.dart) de la interfaz gráfica (screens/menu_screen.dart) facilita que la app crezca sin enredar el código.

Anatomía Detallada del Menú: Drawer y ListView Dinámico

🍔 1. ¿Cómo Funciona el Menú Hamburguesa (`Drawer`)?

Cuando le pasas la propiedad drawer: Drawer(...) al Scaffold, Flutter detecta automáticamente su presencia y coloca el icono de hamburguesa en el AppBar. Al tocar el icono, Flutter abre un panel deslizante lateral que se sobrepone como un Overlay. Para cerrarlo programáticamente usas Navigator.pop(context).

⚡ 2. ¿Cómo Ocurre la Navegación Dinámica?

En lugar de escribir un if/else o switch para cada pantalla, el ListView.builder toma item.pantallaDestino (que es una instancia de la pantalla) y se la pasa directamente a MaterialPageRoute(builder: (_) => item.pantallaDestino). ¡Si agregas 50 herramientas a la lista, el código del menú no cambia!

import 'package:flutter/material.dart';

class CotizadorScreen extends StatefulWidget {
  const CotizadorScreen({super.key});

  @override
  State<CotizadorScreen> createState() => _CotizadorScreenState();
}

class _CotizadorScreenState extends State<CotizadorScreen> {
  final TextEditingController _pesoController =
      TextEditingController(text: '2.5');

  final Map<String, double> _ciudades = {
    'Bogotá': 8000,
    'Medellín': 12000,
    'Cali': 14000,
  };

  final Map<String, double> _velocidades = {
    'Estándar': 0,
    'Express': 5000,
    'Súper Express': 10000,
  };

  String _ciudadSeleccionada = 'Bogotá';
  String _tipoEnvio = 'Estándar';
  bool _conSeguro = false;

  double _total = 0;
  bool _calculado = false;

  @override
  void dispose() {
    _pesoController.dispose();
    super.dispose();
  }

  void _calcularEnvio() {
    final double peso =
        double.tryParse(_pesoController.text.replaceAll(',', '.')) ?? 0;

    setState(() {
      _total = _ciudades[_ciudadSeleccionada]! +
          (peso * 2000) +
          _velocidades[_tipoEnvio]! +
          (_conSeguro ? 3000 : 0);
      _calculado = true;
    });
  }

  String _pesos(double valor) {
    final String entero = valor.round().toString();
    final RegExp patron = RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))');
    return '\$${entero.replaceAllMapped(patron, (Match m) => '${m[1]}.')}';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Cotizador de Envíos'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            TextField(
              controller: _pesoController,
              keyboardType:
                  const TextInputType.numberWithOptions(decimal: true),
              decoration: InputDecoration(
                labelText: 'Peso del paquete (Kg)',
                hintText: 'Ej. 2.5',
                prefixIcon: const Icon(Icons.scale),
                filled: true,
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 16),
            DropdownButtonFormField<String>(
              value: _ciudadSeleccionada,
              decoration: InputDecoration(
                labelText: 'Ciudad de destino',
                prefixIcon: const Icon(Icons.location_city),
                border: OutlineInputBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
              items: _ciudades.keys.map((String ciudad) {
                return DropdownMenuItem<String>(
                  value: ciudad,
                  child: Text('$ciudad  ·  ${_pesos(_ciudades[ciudad]!)}'),
                );
              }).toList(),
              onChanged: (String? valor) {
                if (valor == null) return;
                setState(() => _ciudadSeleccionada = valor);
              },
            ),
            const SizedBox(height: 16),
            Card(
              elevation: 1,
              child: Column(
                children: _velocidades.keys.map((String tipo) {
                  return RadioListTile<String>(
                    dense: true,
                    title: Text(tipo),
                    subtitle: Text('Recargo: ${_pesos(_velocidades[tipo]!)}'),
                    value: tipo,
                    groupValue: _tipoEnvio,
                    onChanged: (String? valor) {
                      if (valor == null) return;
                      setState(() => _tipoEnvio = valor);
                    },
                  );
                }).toList(),
              ),
            ),
            const SizedBox(height: 8),
            Card(
              elevation: 1,
              child: SwitchListTile(
                title: const Text('Seguro de mercancía'),
                subtitle: const Text('Cobertura adicional por \$3.000'),
                secondary: const Icon(Icons.verified_user),
                value: _conSeguro,
                onChanged: (bool valor) => setState(() => _conSeguro = valor),
              ),
            ),
            const SizedBox(height: 20),
            ElevatedButton.icon(
              onPressed: _calcularEnvio,
              icon: const Icon(Icons.calculate),
              label: const Text('COTIZAR ENVÍO'),
              style: ElevatedButton.styleFrom(
                backgroundColor: Colors.indigo,
                foregroundColor: Colors.white,
                padding: const EdgeInsets.symmetric(vertical: 14),
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
              ),
            ),
            const SizedBox(height: 20),
            Card(
              elevation: 0,
              color: Colors.indigo.shade50,
              shape: RoundedRectangleBorder(
                side: BorderSide(color: Colors.indigo.shade100),
                borderRadius: BorderRadius.circular(16),
              ),
              child: Padding(
                padding: const EdgeInsets.all(16.0),
                child: Column(
                  children: [
                    Text(
                      _calculado
                          ? 'VALOR TOTAL COTIZADO'
                          : 'PRESIONA COTIZAR PARA VER EL VALOR',
                      style: TextStyle(
                        fontSize: 11,
                        fontWeight: FontWeight.bold,
                        color: Colors.indigo.shade700,
                      ),
                    ),
                    const SizedBox(height: 6),
                    Text(
                      _calculado ? _pesos(_total) : '--',
                      style: const TextStyle(
                        fontSize: 26,
                        fontWeight: FontWeight.w900,
                        color: Color(0xFF1A237E),
                      ),
                    ),
                  ],
                ),
              ),
            ),
          ],
        ),
      ),
    );
  }

class _CotizadorScreenState extends State<CotizadorScreen> {
  final TextEditingController _pesoController =
      TextEditingController(text: '2.5');

  final Map<String, double> _ciudades = {
    'Bogotá': 8000,
    'Medellín': 12000,
    'Cali': 14000,
  };

  final Map<String, double> _velocidades = {
    'Estándar': 0,
    'Express': 5000,
    'Súper Express': 10000,
  };

  String _ciudadSeleccionada = 'Bogotá';
  String _tipoEnvio = 'Estándar';
  bool _conSeguro = false;

  double _total = 0;
  bool _calculado = false;

  @override
  void dispose() {
    _pesoController.dispose();
    super.dispose();
  }

  void _calcularEnvio() {
    final double peso =
        double.tryParse(_pesoController.text.replaceAll(',', '.')) ?? 0;

    setState(() {
      _total = _ciudades[_ciudadSeleccionada]! +
          (peso * 2000) +
          _velocidades[_tipoEnvio]! +
          (_conSeguro ? 3000 : 0);
      _calculado = true;
    });
  }

  String _pesos(double valor) {
    final String entero = valor.round().toString();
    final RegExp patron = RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))');
    return '\$${entero.replaceAllMapped(patron, (Match m) => '${m[1]}.')}';
  }
